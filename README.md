# NVF Neovim config

This is my personal [NVF](https://github.com/NotAShelf/nvf) configuration with the
[Dim](https://github.com/jeffkreeftmeijer/vim-dim) color scheme. Syntax colors use
the terminal's ANSI palette, and editor and floating-window backgrounds are
transparent, inheriting the terminal's background, opacity, and blur settings.

## LSPs with for Linting and Formatting
- Nix
- Bash
- Python
- TS/JS
- Terraform
- Cmake
- Markdown
- HTML/CSS
- JSON, YAML, TOML
- Helm
